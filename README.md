## 🇬🇧 English

### About

The **AI Architecture Studio Director** is a comprehensive architectural intelligence system designed to serve as the permanent core of a professional architecture studio. It unifies design thinking, technical analysis, quality control, project management, client communication, and continuous learning into a single, coherent framework.

> This environment does not execute architectural projects. It builds the **underlying intelligence** that powers all project workspaces.

### ✨ Key Features

| Feature | Description |
|---------|-------------|
| 🧠 **Architectural Thinking Engine** | Problem definition, 7-dimension analysis, design reasoning |
| 🔒 **Source Lock & Edit Integrity** | Truth hierarchy, geometry lock, authorized delta, P0-P6 failure codes |
| ⚡ **Cognitive Pipeline** | 16-stage structured reasoning process |
| 🏗️ **12 Virtual Specialists** | Multidisciplinary team with intelligent activation rules |
| 📊 **AQS Quality System** | 7-criteria evaluation matrix + 6 quality gates |
| 🇮🇷 **Iranian Regulations** | 22 official Mabahes + 2 supplementary compliance modules + municipal rules |
| 💼 **Business Intelligence** | Pricing engine, negotiation, financial learning |
| 🤝 **Client Communication** | 6 communication modes + 4 client psychology types |
| 🎨 **Visual Identity** | Custom graphic language, color palette, typography |
| 🧬 **5-Layer Memory** | From temporary memory to permanent knowledge |
| 🔄 **Continuous Evolution** | System becomes smarter with every project |

## 📦 Release & Distribution Policy

This policy concerns repository distribution only; it does **not** change the four core intelligence files.

- Markdown source files are versioned in Git.
- Official downloadable ZIP and PDF packages are published as **GitHub Release Assets**, together with a version tag, release notes, and SHA-256 checksum.
- Generated ZIP/PDF bundles are not committed as ordinary repository source files; they are built from the tagged source at release time.
- Every release package includes a manifest listing the included files, source commit, package date, version, and checksum.
