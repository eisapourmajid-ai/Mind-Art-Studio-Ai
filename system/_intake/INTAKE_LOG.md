## Intake Rules — Current

1. Every dictated item is classified before placement: identity, reasoning, knowledge, or routing.
2. Placement follows `01_CORE.md` 40.09 File Responsibility Boundary.
3. No value is invented. Unknown fields are recorded `Undefined` or `Pending Decision`.
4. Every permanent rule carries Source, Reason, and Approval.
5. Every file touched receives a changelog row in `02_LIBRARY.md` Section 05.
6. Original numbering supplied in dictation has no authority over final structure.
